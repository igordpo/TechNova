# TechNova Solutions — Portal Institucional

Portal institucional responsivo desenvolvido em HTML5 semântico e CSS3 para a **TechNova Solutions**, apresentando serviços tecnológicos, equipe de especialistas, tabela comparativa de planos, central de notícias e formulário de contato.

## 🚀 Tecnologias e Recursos Implementados
* **HTML5 Semântico:** Estrutura acessível com formulário corporativo validado, tabela comparativa (`rowspan` e `colspan`) e ícones vetoriais **SVG inline**.
* **CSS3 Moderno:** Grid Layout, Flexbox, variáveis CSS (`:root`), cabeçalho fixo (`sticky`), etiquetas sobrepostas no blog (`relative`/`absolute`), tabela zebrada (`:nth-child`) e microinterações no `:hover`.
